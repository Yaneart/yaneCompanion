# Установка и обслуживание yaneCompanion

## Установка и запуск

Скачайте пакет для своей системы в [GitHub Releases](https://github.com/Yaneart/yaneCompanion/releases).

| Система x64 | Установка | Запуск |
| --- | --- | --- |
| Windows 10 2004 или новее, Windows 11 | Откройте `.exe` и завершите установку для текущего пользователя | Найдите **Yane** в меню «Пуск» |
| Debian 12, Ubuntu 24.04 | Откройте `.deb` в пакетном менеджере или выполните `sudo apt install ./<файл>.deb` | Найдите **yaneCompanion** в меню приложений |
| Arch Linux | Выполните `sudo pacman -U ./<файл>.pkg.tar.zst` | Найдите **yaneCompanion** в меню приложений |

На Linux программу также можно открыть командой `yanecompanion` от обычного
пользователя. TorrServer и FFmpeg входят в установочные пакеты.

В Windows мастер может добавить ярлык **Yane** на рабочий стол. Язык установщика
можно выбрать аргументом `/LANG=ru` или `/LANG=en`.

## Подключение к сайту

1. Запустите yaneCompanion. Если адрес сайта ещё не задан, откройте
   **Настройки** и сохраните точный HTTPS-адрес yaneMedia без пути.
2. Выберите торрент на сайте, нажмите **Подключить yaneCompanion** и при запросе
   браузера разрешите доступ к локальной сети.
3. Сверьте адрес и шестизначный код на сайте и в приложении. Нажмите
   **Разрешить** в yaneCompanion. Видео откроется в браузере.

Ссылка `yanecompanion://open` открывает приложение. Подключение подтверждается
в окне yaneCompanion. Сохранённое разрешение можно отозвать в **Настройках**.
Смена адреса отзывает доступ предыдущего сайта.

Крестик сворачивает приложение в трей, если окружение поддерживает трей.
Пункт **Выйти** закрывает приложение и останавливает просмотр. Автозапуск можно
включить в **Настройках**.

## Обновление и откат

Откройте **Поддержка → Проверить обновления**. Если канал настроен, приложение
предложит скачать текущий пакет и, при наличии, предыдущую версию. Загрузка
доступна после завершения активного просмотра.

В папке пакетов текущая версия находится в `current/`, предыдущая — в `previous/`.
Закройте yaneCompanion через **Выйти** и установите скачанный пакет обычным
способом. Для отката установите предыдущий пакет. Настройки и подключения
сохраняются при совместимом формате профиля.

В **Поддержка → Диагностика** можно скопировать технический отчёт.

## Удаление

Закройте yaneCompanion через **Выйти**. В Windows откройте список установленных
приложений и удалите **yaneCompanion**. На Debian и Ubuntu выполните
`sudo apt remove yanecompanion`, на Arch — `sudo pacman -R yanecompanion-bin`.

Для удаления кэша и разрешений после закрытия программы доступны команды
`yanecompanion clean-data --cache` и `yanecompanion clean-data --pairings`.
