# Проверки yaneCompanion

## Установка по платформам

| Система x64 | Результат |
| --- | --- |
| Windows 10 Home, сборка 19045 | Проверены установка, регистрация `yanecompanion://`, запуск и удаление. Минимум установщика — Windows 10 2004, сборка 19041. |
| Windows 11 | Отдельная проверка установки не проводилась. |
| Debian 12, Ubuntu 24.04 | Установка, запуск и удаление `.deb` проверены в контейнерах. Интерфейс GTK проверен в Debian под Xvfb. |
| Arch Linux | Установка пакета проверена в контейнере. Отдельно подтверждён запуск приложения из клона на Arch. |

Локально проверены сопряжение, отзыв доступа, воспроизведение, раздельный звук,
диагностика и загрузка пакета через подписанный тестовый манифест. Обновлятор
скачал публичный файл GitHub Releases и отклонил переходы на неподдерживаемые хосты.

Проверка на публичном HTTPS-сайте, установленные пакеты Linux в нативной
среде, длительное воспроизведение и 4K/HDR ещё не подтверждены. У раздач без
пригодного индекса субтитров подготовка ограничена 128 МиБ и может вернуть
`RESOURCE_LIMIT`. Видео и звук продолжают воспроизводиться.

<a name="lc-013--устойчивость-и-замеры-2026-11-19"></a>

## Локальный замер воспроизведения

На Windows 10 и Chromium с контрольным файлом H.264 подготовка заняла
6,56 с, перемотка за пределы буфера — 6,81 с, переключение звука — 2,70 с.
Пиковые выборочные значения памяти для помощника и обнаруженных дочерних процессов
составили 62,62 МиБ RSS и 90,24 МиБ private. Замер использовал локальный файл и
не включает загрузку с пиринговой сети или память браузера.

## Повтор проверок

Для проверки настройки рабочего окна и обновлятора:

```powershell
$env:GOTOOLCHAIN = 'local'
$env:GOMODCACHE = Join-Path (Get-Location) '.tools\go-mod'
$env:GOCACHE = Join-Path (Get-Location) '.tools\go-cache'
& .\.tools\go\bin\go.exe test ./internal/desktop ./internal/update ./cmd/release-manifest
```

Для повторного замера воспроизведения установите `YANE_TEST_EXECUTABLE` на
`dist/windows-amd64/yanecompanion.exe` и запустите
`go test ./internal/api -run '^TestLC013PlaybackBudgets$' -v -count=1 -timeout 120s`.

Хеши собранных пакетов находятся в `dist/packages/packages.json`.
Сведения о воспроизводимости сборок приведены в
[манифесте приложения](../release/runtime-build.json) и
[манифесте движка](../release/engine-build.json).
